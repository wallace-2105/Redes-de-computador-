# RedeMaster | Portal de Estudos em Redes de Computadores

Portal de estudos interativo e completo para provas de Redes de Computadores, contendo Resumo Teórico com blocos sanfonados, Calculadora de Sub-redes IPv4 e um Simulado com 30 questões comentadas.

## 📁 Estrutura do Projeto

```text
Redes-de-computador-/
│
├── index.html          # Estrutura HTML da Single Page Application
├── css/
│   └── style.css       # Estilos visuais, variáveis, dark/light theme e responsividade
├── js/
│   └── app.js          # Lógica do Quiz, calculadora IPv4, filtros e gabarito comentado
└── README.md           # Documentação do projeto
```

## 🚀 Como Executar

Não é necessário instalar nenhuma dependência ou servidor:
1. Basta abrir o arquivo [`index.html`](index.html) diretamente com dois cliques em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).
2. Ou via terminal:
   ```powershell
   Start-Process index.html
   ```

## 📚 Conteúdo Teórico e Simulado

- **Comunicação de Dados:** Transmissor, Receptor, Meio/Canal e Protocolo.
- **Modelos de Referência:** Modelo OSI (7 camadas) e TCP/IP (4 camadas).
- **Tipos de Redes e Topologias:** PAN, LAN, MAN, WAN; Estrela, Barramento, Anel, Árvore e Malha Completa.
- **Equipamentos de Interconexão:** Repetidor/Hub (L1), Bridge/Switch (L2), Roteador (L3), Gateway (L4-L7).
- **Ethernet:** Padrões (10M a 10G), CSMA/CD em Half-Duplex vs Full-Duplex, modos de comutação e Flow Control (802.3x).
- **Cálculo de IP (IPv4):** Conversão decimal-binário, classes, máscaras CIDR, hosts válidos e ferramenta calculadora integrada.
- **Simulado de 30 Questões:**
  - 10 Fáceis (1 a 10)
  - 10 Médias (11 a 20)
  - 10 Difíceis (21 a 30)
- **Gabarito Completo:** Explicação técnica detalhada para cada questão no relatório final.
